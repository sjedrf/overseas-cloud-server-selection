## 标称 5Gbps 不等于国内访问快

Akile 最显眼的参数是端口带宽，洛杉矶全系 5Gbps、日本 Hyper 系列 2.5Gbps。这个数字是端口速率上限，不是国内下载速度。

优化线路的端口通常很小。第三方测评里提到，多数商家的香港 CN2 线路只给几 Mbps 到 100Mbps，HostKVM 香港给到 100Mbps CN2 已经算大带宽。反过来，标称 1000Mbps 却走国际线路的机器，国内实测可能只有几十兆。带宽和线路类型是两个数，要一起看。

更实际的一层是流量。端口跑满只是理论值，月度流量才是真约束：

- LAXLite-One：5Gbps 跑满约 625MB/s，1TB 月流量不到半小时就耗尽
- JPHyper-Lite：2.5Gbps 跑满约 312MB/s，1TB 月流量约 56 分钟耗尽
- HKLite-Mini：1Gbps 跑满约 125MB/s，2.5TB 月流量约 5.8 小时耗尽

所以这类“大端口 + 小流量”的套餐，卖的是峰值能力和并发能力，不是让你 24 小时满速下载。适合放静态资源、做中转、多人共用、给视频站做分片，或者给海外用户访问；不适合当国内访客为主的电商主站，那边需要的是低延迟线路，不是大端口。

## 常见问题

**免备案是不是什么都不用管？**
免的是国内 ICP 备案流程，香港、日本、美国节点开通即可解析。机房所在地的法律法规仍然适用，这条不能省。

**延迟多少算正常？**
按第三方测评口径：香港优化线路 40～70ms，日本 60～120ms，美国西海岸优化线路 150～180ms、普通线路 190～230ms。超过 250ms 基本可以判定绕路。

**带宽和流量有什么区别？**
带宽是瞬时速率，单位 Mbps 或 Gbps；流量是一个月能传多少数据，单位 GB 或 TB。5Gbps 配 1TB，意思是峰值很快、总量很小。

**5Gbps 真能跑到 5Gbps 吗？**
端口速率是上限，实际速度取决于对端、线路和并发。国内访问普通国际线路，很难接近端口标称值。这个数字的意义在于并发能力，不在单线程下载速度。

**IP 被封了怎么办？**
资料里没有 Akile 免费换 IP 的政策说明，下单前问客服。行业里 DigitalCloud、Hostwinds、justhost.asia、Kamatera 支持后台免费换 IP，可以当作选商家的一个加分项。

**能退款吗？**
Akile 没有公开退款条款可查，以官网服务条款为准。
